# OCR 合规样张生成提示词预案

> 当前用途：作为正式 skill 之前的预先测试版本。目标是复现首页 Banner 样张的方法，生成“版式辨识度强、但明显不可用”的 OCR 材料样张。

## 适用范围

- 身份证、护照、户口本、驾驶证、行驶证、社保卡等个人证件。
- 营业执照、开户许可证、不动产权证等机构/权属类材料。
- 增值税发票、机动车销售统一发票、二手车发票、出租车票、火车票、回收凭证等票据。
- 合同、回执、通用文本等文档类材料。

## 生成原则

- 证件/票据本体优先保留真实材料的常见版式关系、信息密度、字段排列、标题层级、照片/二维码/印章/边框区域，但不要生成可被误认为真实签发材料的完整复刻。
- 所有文字必须清晰可读，便于后续做 OCR 字段来源对照。
- 所有身份、企业、地址、号码、日期、机关、金额均必须明显虚构或无效。
- 必须加入醒目的 `SAMPLE`、`示例`、`样张`、`无效`、`仅供字段来源示意` 等标记之一或多个。
- 不生成真实可验证号码，不生成真实个人肖像，不复刻可被误用的防伪细节、真实公章、真实国徽或可扫描二维码。
- 输出应是单个材料本体，透明背景或极简浅色背景；不要生成桌面场景、手持、夹子、UI 卡片、现代 SaaS 面板。

## 安全合规降级策略

如果图像模型拒绝生成，或提示词被判断为“生成真实证件/票据”，按下面顺序降级，不要反复要求模型绕过限制：

1. 先生成“不可用材料外壳”：只包含版式、边框、底纹、照片/二维码占位框和大号 `SAMPLE 示例` 水印，不要求模型生成完整可读证件文字。
2. 再用本地脚本或设计工具叠加虚构中文字段、全 0/全 X 号码、无效日期和字段来源标记。
3. 对个人证件，照片优先使用抽象头像或明显虚构头像；不要要求“真实证件照”或“逼真人像”。
4. 对证照、发票，二维码必须是不可扫描的方块纹理；公章、国徽、税章、监管机关标识必须抽象化。
5. 仍被拒绝时，改用 CSS/HTML/SVG 本地绘制字段来源示意，不继续提高真实感。

## 通用主提示词

将 `{材料类型}`、`{版式要点}`、`{字段清单}`、`{虚构内容规则}` 替换为具体材料。

```text
生成一张不可用的 OCR 识别材料示意样张，材料类型为：{材料类型}。

画面只包含一份材料本体，正面平铺展示，轻微自然纸张/卡片质感，边缘干净，可用于网页透明背景素材。不要生成桌面、手、夹子、文件夹、网页 UI 或展示场景。

版式应参考该类材料的常见结构和字段位置关系，但必须明显是不可用的示例样张：
{版式要点}

字段文字必须清晰可读，字段位置和信息密度要适合 OCR 字段来源对照。请包含以下字段区域：
{字段清单}

全部内容必须明显虚构和无效：
{虚构内容规则}

在材料上加入醒目的红色或蓝色斜向样张章，文字为 “SAMPLE 示例” 或 “仅供字段来源示意”。不要生成真实有效证件、真实号码、真实机构、真实个人身份信息、真实官方印章、真实国徽或可验证二维码。照片如需要，只能是虚构头像或抽象证件照占位，不要像真实身份证照片；二维码如需要，只能是不可扫描的示意码。

视觉风格要求：
- 保持材料类别可辨认的比例、留白、字体层级、字段密度和区域关系。
- 文字清晰，不要乱码，不要伪文字，不要让字段名缺失。
- 材质可以有轻微纸纹、印刷纹理、旧纸边、扫描感或透明裁切边。
- 不要过度美化成海报、插画、纪念品、银行卡式通用卡片或现代软件界面。

输出规格：
- 单张横向或纵向材料本体图。
- 高分辨率，长边至少 1000px。
- 背景透明优先；如果无法透明，则使用纯净浅色背景，方便后期抠图。
```

- 可有浅蓝/浅红抽象底纹，但不要复刻完整真实防伪纹路。

{字段清单}
- 姓名：示例样本

- 民族：XX
- 出生：19XX 年 XX 月 XX 日
- 住址：XX省XX市XX区XX路XX号 XX小区X栋X单元XXX室

## 输出后处理建议

- 如果图像模型无法直接输出透明背景，先生成浅色背景，再用抠图工具生成 `*-specimen-alpha.png`。
- 用 `sharp` 或现有 `scripts/optimize-home-assets.mjs` 转成 WebP，命名为 `xxx-specimen-alpha.webp`。
- 首页/卡片预览直接使用透明样张图；字段来源模块在样张图上叠加前端热区。
- 热区数据使用百分比坐标：`x/y/w/h`，不要硬编码像素，便于响应式缩放。

## 验收清单

- 一眼能识别材料类型。
- 字段名和字段值清晰可读。
- 字段位置和真实材料常见位置一致。
- 至少一个醒目的 `SAMPLE`/`示例`/`无效` 标记。
- 无真实可用身份号码、信用代码、二维码、VIN、发票号码或地址。
- 不像现代 UI 卡片，不像插画海报，不像通用宣传图。
- 可以作为前端透明样张资产嵌入，不依赖复杂背景。
